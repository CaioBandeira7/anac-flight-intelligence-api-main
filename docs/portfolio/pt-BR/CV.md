# Descrição para currículo — português

**ANAC Flight Intelligence** · Python, Polars, DuckDB, LightGBM, FastAPI, Next.js e Groq.

- Direção de uma plataforma de dados sobre 22.120.241 registros ANAC, com ingestão auditada em Parquet, camada analítica de sete tabelas e aplicação FastAPI/Next.js publicada.
- Avaliação temporal de quatro regressores LightGBM contra dez referências de baseline; manutenção do baseline de A por ganho inconclusivo e divulgação da limitação histórica de D, sem alegar performance do treino corrigido.
- AI Analyst com ferramentas fixas, verificação numérica heurística e limites de uso. Validação consolidada: 368 testes Python aprovados, 11 ignorados; 91 frontend aprovados.

Implementação assistida por Claude Code e Codex, sob direção, revisão e aprovação humana. D não foi retreinado; holdout parcialmente exposto, não pontuado; C não treinado; sem previsão futura operacional ou impacto comercial medido. [Versão principal em inglês](../CV.md).
